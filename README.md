# 👑 The Royal Heritage — Sri Lankan Traditional Digital Wedding Invitation
### ශ්‍රී රාජකීය සාම්ප්‍රදායික මංගල ඇරයුම

A 100% bespoke, original, luxury digital wedding invitation web application celebrating the authentic cultural heritage of Sri Lanka (Hansa Puttuwa, Punkalasa, Sandakada Pahana, Royal Talpath/Ola Leaf Manuscripts, and Nakath ceremonies).

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Web Audio API**.

---

## 🌟 Groundbreaking Features (ශ්‍රී ලංකාවේ ප්‍රථම වරට)

1. **Personalized VIP Guest Plaque (පෞද්ගලික ආරාධනා නාම පුවරුව)**:
   - Dynamic URL query support (`?to=ගෞරවනීය_සුනිල්_පෙරේරා_සහ_පවුල`).
   - Automatically renders a personalized royal gold invitation plaque for each guest.
2. **Royal Palm-Leaf Manuscript (තල්පත / පුස්කොල පොත) Unveiling Experience**:
   - Instead of a generic paper card, the invitation is sealed like an ancient royal decree that gently unrolls with a golden cord.
3. **Interactive Nakath & Poruwa Rituals Timeline (පෝරු චාරිත්‍ර හා නැකත් පෙළ)**:
   - Interactive stepper showing key auspicious moments (Departure of Bride, Ascending the Poruwa, Water Blessing, Milk Rice, Banquet) with cultural significance.
4. **Virtual Aashirwada Mandapaya (ආශිර්වාද මණ්ඩපය)**:
   - Real-time guest blessing wall with cultural stamps (🪷 ජය මංගලම්!, 🌾 සිරි සුබ මංගලම්!, 🪔 දීර්ඝායු වේවා!, 🕊️ සදා සතුට!) and golden celebration confetti.
5. **1-Click Smart WhatsApp RSVP**:
   - Guests can confirm attendance with 1 tap, automatically generating a pre-formatted Sinhala or English message to the couple's WhatsApp.
6. **100% Bespoke Cultural Vector Art**:
   - Custom SVG art: **Hansa Puttuwa** (Sacred Swans of Fidelity), **Punkalasa** (Pot of Abundance), **Sandakada Pahana** (Sacred Moonstone Arcs), and **Royal Liyawel** dividers.
7. **Pure Web Audio API Auspicious Soundscape**:
   - Peaceful meditative temple chimes generated in real-time via Web Audio API. Zero external audio dependencies and zero copyright issues.
8. **3 Dynamic Royal Color Themes**:
   - **ස්වර්ණ (Swarna)**: Royal Gold & Warm Ivory
   - **නීලමේ (Nilame)**: Kandyan Royal Crimson Maroon & Antique Brass
   - **හරිත (Haritha)**: Temple Emerald & Champagne Gold
